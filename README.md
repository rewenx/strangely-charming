# Strangely Charming

A native Horizon mod by EvanderFox, adding runic travel, exploration, quality-of-life features, and decorative blocks.

## [Visit the Strangely Charming guide](https://evander.wtf/sc/)

Find feature explanations, screenshots, and downloads on the website. Strangely Charming requires Horizon; see the [Horizon listing](https://playhorizon.dev/mods/strangely_charming) for supported builds.
